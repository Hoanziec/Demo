# STEM lớp 4 – Vật dẫn nhiệt tốt, vật dẫn nhiệt kém

Website tĩnh, **không cần server**, phù hợp GitHub Pages và điện thoại.

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload `index.html` và file `.nojekyll`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch → main → /(root)**.
5. Lưu lại và mở địa chỉ GitHub Pages được GitHub cấp.

## Các chức năng
- Giao diện responsive theo phong cách màn hình mẫu.
- 12 bước học tập.
- Video YouTube.
- 5 câu hỏi sau video, chấm đúng/sai và hiện đáp án câu sai.
- Kiến thức nền: chạm để xem.
- Chọn vật liệu và mô phỏng nhiệt độ.
- Kéo thả trên máy tính; trên điện thoại hỗ trợ chạm vật → chạm nhóm.
- Trắc nghiệm nhiều đáp án, hiện các lựa chọn đúng/sai.
- Phiếu ý tưởng thiết kế và trang xem lại.
- Tổng điểm.

## Lưu ý về nhiệt độ
Các nhiệt độ hiển thị là **mô phỏng minh họa dưới cùng một điều kiện giả định** (nước 80°C, vật ban đầu 25°C, 30 giây, cùng kích thước/điều kiện). Nhiệt độ thực tế không thể xác định chỉ từ tên vật liệu vì còn phụ thuộc hình dạng, khối lượng, diện tích tiếp xúc, thời gian và môi trường.
